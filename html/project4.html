01 / The challenge

Public datasets seldom fit neatly together.

Road accidents happen in a wider context. Location, timing, traffic conditions and weather may all matter, but the relevant information is spread across multiple sources.

The project combined descriptive analysis with predictive modelling, seeking to understand accident-severity patterns and present the findings in a format people could explore.

02 / The approach

Integrate data. Map patterns. Test models.

The work linked exploratory analysis with interactive data storytelling and traditional supervised machine learning.

01 / INTEGRATE

Build a usable dataset

Combine NYC collision records with weather and speed-limit data, then prepare the features and address missing values.

02 / EXPLORE

Make patterns visible

Investigate temporal trends, geographic hotspots and contributing factors using plotting, Folium maps and Bokeh dashboards.

03 / MODEL

Compare classical classifiers

Experiment with logistic regression, decision trees and random forests while considering class balance and feature importance.

03 / The findings

What the project delivered.

▦

◇

It experimented with classification methods to assess accident severity using features from multiple data sources.

◎

Features worth investigating

The original write-up discusses contextual variables such as location, vehicle type and weather as potentially relevant signals.

Evidence note: The old project page reports accuracy above 60%, but without the associated class balance and evaluation definition here, that percentage is not presented as an overall quality claim. Observed associations are not proof of causation.

04 / The takeaway

Good analysis is more than a prediction.

The project demonstrates the value of combining data engineering, modelling and visual storytelling. A model score is only one part of making a dataset useful.

Presenting limitations and helping readers explore the underlying patterns can be just as important as selecting a particular algorithm.
